# YUNG-S-KEBAB - Multi-Purpose Savings Platform

A web application that allows users to save money for different purposes (food, marriage, equipment, etc.) with bank account integration.

## Features

- 💰 Multiple Savings Goals: Create and manage individual savings purposes
- 🏦 Bank Integration: Link bank accounts or cards to each purpose
- 📊 Real-time Tracking: View accumulated savings for each purpose
- 💳 Balance Visibility: Display remaining balance on linked card/account
- 🔄 Flexible Deposits: Add more savings to any purpose at any time
- 💸 Withdrawal Management: Withdraw from specific savings goals
- 📈 Total Overview: See total savings across all purposes

## Project Structure

- frontend/ - React/Vue web app
- backend/ - API server
- database/ - Database schemas
- docs/ - Documentation
